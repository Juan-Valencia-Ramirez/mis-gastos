# Mis Gastos

Registro de gastos para el celular. Guarda cada compra en el teléfono y la copia en un repositorio privado de GitHub.

Los topes del gasto variable son $35.000 al día, $245.000 a la semana y $1.050.000 al mes. La categoría Fijo queda por fuera de esos topes.

## Usarlo en el celular

1. Publica esta carpeta con GitHub Pages, o ábrela desde una dirección HTTPS.
2. En GitHub, crea un token fine-grained con acceso solo al repositorio de datos y permiso Contents de lectura y escritura.
3. Abre Mis Gastos, entra en Ajustes y pega el token. El repositorio sugerido es `mis-gastos-datos`.
4. En iPhone, usa Safari: Compartir, luego Agregar a pantalla de inicio.

El token no se guarda en el repositorio. Queda solo en el celular.
